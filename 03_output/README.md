# 03_output

**Chứa:**
- Sản phẩm không phải code (tài liệu, báo cáo, dữ liệu bàn giao).
- `CYC-nn/checks/` — bằng chứng kiểm của task và bản ghi kiểm định `RVW-CYC-nn.md`.

**Ai ghi:**
- WORKER: chỉ các file trong `write_scope` của task và bằng chứng trong `CYC-nn/checks/`.
- REVIEWER: chỉ `CYC-nn/checks/RVW-CYC-nn.md`.

**Giới hạn:** không giới hạn số dòng cho sản phẩm. Sản phẩm và dữ liệu bàn giao không chứa ghi chú (`harness/HARNESS.md` mục 8.4).

**Lưu ý:** mã nguồn và test của dự án code nằm ở `product_paths` trong `harness.yaml`, không nằm ở đây. File dữ liệu thật không vào repo.
