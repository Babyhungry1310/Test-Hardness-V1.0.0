# 06_sources 🔒

**Chứa:** `SRC-nnnn_<slug>.*` — nguồn chuẩn đã được OWNER duyệt.

**Ai ghi:** LEAD cấp mã `SRC-nnnn` và thêm file sau khi quét bằng script `scan`; chỉ có hiệu lực khi OWNER merge. WORKER và REVIEWER không ghi.

**Giới hạn:** không giới hạn số dòng. File nhị phân lớn không vào repo.

**Lưu ý:** nội dung từ bên ngoài chỉ vào repo qua thư mục này. Dữ liệu thật, nhạy cảm (Zone 2) và bí mật (Zone 3) không bao giờ đặt ở đây. Đuôi file dữ liệu thật bị `.gitignore` chặn.
